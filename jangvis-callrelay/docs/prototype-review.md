# 원본 프로토타입(0.1.0-test) 검토 결과

현재 구현(`app/src/main/java`)은 원본의 10개 클래스 구조를 유지하고, 아래 문제를 고친 것이다.
원본 검사 사례(22개 정책 검사)는 `PolicyTest`에 회귀 검사로 옮겼다.

## 실제 동작을 막는 문제

| # | 위치 | 원본 동작 | 영향 | 현재 구현 |
|---|---|---|---|---|
| 1 | `Dynalist.post` | `"OK".equals(_code)`만 성공 | Dynalist 실제 응답은 `"Ok"` → **모든 조회·전송이 실패**(ApiError "Ok"), 연결 확인도 실패 | `Ok`(대소문자 무시)만 성공, 나머지 코드는 종류별 처리 |
| 2 | `UploadJob` | 항목 목적지 ≠ 현재 설정 문서면 `error` | 설정을 바꾸면 기존 항목이 멈추고, 원래 문서로 되돌려야 함 | 항목마다 고정된 원래 문서로 계속 전송 |
| 3 | `UploadJob` / `Queue.items()` | 한 번에 3건, 남으면 시스템 지수 백오프로 재실행 | 대기 건이 많으면 30초→1분→2분…로 점점 느려짐 | 20건씩 반복 처리, 시간 예산 초과 시 즉시 재예약 |
| 4 | `UploadJob` (uncertain) | 대조해서 없으면 "재전송하지 않음"으로 영구 정지 | 응답 손실 후 서버에 실제로 없던 항목이 영원히 안 감 | 2분 뒤 대조 → 없으면 재전송, 5회 넘으면 사용자 확인 대기 |
| 5 | `Policy.completed` | "텍스트 변환" + "완료"가 어디든 있으면 완료 | "녹음 완료 / 텍스트 변환 중"을 완료로 오판 → 변환 전 자동화 시작 | 진행 중·실패·부정 문구가 있으면 시작 안 함 |
| 6 | `SamsungListener` | `pending_key` 하나만 저장 | 연속 통화 시 첫 번째 완료 알림이 덮어써져 누락 | 최대 10건 대기열, 순서대로 처리 |
| 7 | `ShareActivity` | `EXTRA_TEXT`가 있으면 파일보다 우선 | 삼성이 미리보기 문구를 함께 넣으면 전체 녹취 대신 일부만 저장될 수 있음 | 파일(`EXTRA_STREAM`) 우선 |
| 8 | 통화 식별 | 자동화는 알림 키, 수동은 파일명으로 ID 생성 | 같은 통화를 자동·수동으로 한 번씩 보내면 Dynalist에 2건 | 파일명이 있으면 항상 파일명 기준 |

## 안전·견고성

- `SamsungAutomation` 3단계에서 대상이 안 보이면 다시 "공유"를 누름 → 공유 화면의 다른 "공유" 버튼을 누를 수 있음. 현재: 공유 화면은 스크롤만 하고, 못 찾으면 중단.
- 허용 창에 `com.android.systemui` 포함 → 알림창의 "공유" 등을 누를 수 있음. 현재: systemui는 기다리기만 하고 누르지 않음.
- 취소 수단이 자동 전송 끄기뿐. 현재: 진행 알림의 '취소' 버튼 + 앱 화면 '자동화 취소'.
- Android 14+에서 알림 PendingIntent를 백그라운드에서 보낼 때 실행 허용 옵션 없음. 현재: `ActivityOptions`로 명시(실기기 확인 필요).
- 토큰을 확인하기 전에 저장 → 잘못된 토큰이 저장됨. 현재: `doc/read`로 확인 후 저장.
- HTTP 오류(429 포함)와 연결 실패를 모두 `uncertain`으로 처리. 현재: 요청 전 실패는 재시도, 429는 백오프, 본문 전송 후 응답 손실만 `uncertain`.
- 상태 전이가 무조건 UPDATE(`state(id, …)`) → 늦게 끝난 작업이 결과를 덮어쓸 수 있음. 현재: 선점 토큰이 일치할 때만 전이.
- 알림 진단이 "패키지 · 완료 감지 여부"만 보여줘 실제 문구를 알 수 없음. 현재: 상태 단어만 남긴 문구 골격을 기록(이름·번호·본문 제외).

## 원본에서 가져온 것

- `doc/edit` 응답의 `results` 배열 검사(있는데 성공이 아니면 서버 대조로 확인).
- 공유가 선택창으로 열릴 때 '한 번만' 누르기(공유 화면 후보 패키지 안에서만, '항상'은 누르지 않음).
- 원본 정책 검사 사례 전부. 이 중 "텍스트 변환이 완료되지 않았습니다"가 현재 구현의 오판을 잡아내 수정했다.
